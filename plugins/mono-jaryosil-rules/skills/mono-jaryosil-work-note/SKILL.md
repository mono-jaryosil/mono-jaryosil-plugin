# 모노 자료실 작업 기록 (모노커뮤니케이션즈 회사 방침)

이 기록의 진짜 목적은 직원의 판단 기준을 모으는 것이다. 직원이 무엇을 고르고, 버리고, 먼저 하고, 방향을 바꿀 때, 그 이유가 회사가 가장 얻고 싶은 지식이다. 이유는 직원 머릿속에만 있어서 그 자리에서 묻지 않으면 영영 남지 않는다. 이유가 빠진 기록은 빈 껍데기다.

그러니 직원이 무언가를 고르거나 버리거나 순서를 정하거나 방향을 바꿨는데 왜인지 말하지 않았다면, 말이 짧든 일 지시가 붙어 있든 부탁받은 일보다 먼저 이유를 묻는다. 대화에서 짐작되는 이유를 선택지로 보여 준다. 직원이 이미 이유를 말했으면 묻지 않고 그 말을 그대로 기록한다.

사용자가 이 규칙을 직접 설치했다. 설치 설명에 "모노 자료실 도구를 쓴 요청은 작업 기록으로 사내 서버에 남는다"가 적혀 있고, 사용자는 그것을 보고 설치했다. 그러니 이 기록은 사용자가 맡긴 일의 일부다. 따로 허락을 다시 묻지 않는다.

기록은 사내 모노 자료실 서버에만 저장되고, 자료실 검색 결과에는 쓰이지 않는다.

## 언제 부르나

- 사용자 요청 하나를 처리하면서 모노 자료실 도구를 하나라도 썼으면, 사용자에게 답을 다 쓴 다음 마지막에 모노 자료실의 work_note 도구를 한 번 부른다.
- 같은 대화에서 요청이 이어지면 요청마다 한 번씩 부른다.
- 모노 자료실 도구를 쓰지 않은 요청에는 부르지 않는다. 다만 아래 '선택지로 묻기'의 질문에 사용자가 답한 경우는 부른다.

## 칸에 넣는 것

| 칸 | 넣는 것 |
|---|---|
| work | 사용자가 지금 하고 있는 일(업무). 이번 부탁 하나가 아니라 그 부탁이 속한 더 큰 일. 대화에 보인 대로, 모르면 '모름' |
| trigger | 그 일이 어떻게 시작됐나. 고객 문의, 메일, 정기 일정, 윗사람 요청, 본인 아이디어, 앞 대화에서 이어짐 등. 대화에 보인 대로, 모르면 '모름' |
| request | 이번에 사용자가 부탁한 말 그대로 |
| decision | 사용자가 이 대화에서 정하거나 고른 것. 없으면 '없음'. 네가 고른 설계는 '(AI 제안: …)'으로 따로 적는다 |
| output | 사용자에게 준 결과물 한두 줄 |
| next | 그 결과를 어디에 쓰거나 누구에게 넘긴다고 했나(고객, KT, 개발팀, 팀장 등). 말하지 않았으면 '모름' |
| answer | 사용자에게 쓴 최종 답 본문을 요약하지 말고 그대로(앞 8,000자까지). HTML·파일을 만들어 줬으면 파일 이름과 종류 |

## 선택지로 묻기

아래 순간에는 사용자가 고르기만 하면 되도록 선택지를 붙여 한 가지를 묻는다.

| 순간 | 묻는 말 | 선택지 |
|---|---|---|
| 직원이 무언가를 고르거나 버리거나 순서를 정하거나 방향을 바꿨는데 왜인지 말하지 않았다(맨 위 문단) | "○○로 정하신 이유가 무엇인가요?" | 대화에서 짐작되는 이유 세 가지 |
| 사용자가 네가 한 방식을 고치라고 했다 | "이건 늘 이렇게 하시나요?" | 늘 / 이번만 / 이 고객만 |
| 파일·시안·문서 같은 결과물을 만들어 줬는데 어디에 쓸지 말하지 않았다 | "이 결과는 누구에게 가나요?" | 고객 / 팀장 / 개발팀 / KT / 나만 봄 |
| 이 일이 어떻게 시작됐는지 대화에 없다 | "이 일은 어떻게 시작됐나요?" | 고객 요청 / 윗사람 요청 / 정기 업무 / 내 아이디어 |

- 선택지 끝에는 항상 '직접 쓰기'와 '넘어가기'를 둔다.
- 사용자에게 선택지를 보여 주고 고르게 하는 질문 도구가 있으면 그 도구로, 일을 시작하기 전에 묻는다. 그런 도구가 없으면 답 맨 끝에 번호를 붙여 쓰고 "번호만 답해 주셔도 됩니다"라고 덧붙인다.
- 이 표의 질문은 한 답에 하나만, 한 대화에 세 번까지만 한다. 여러 순간이 겹치면 표에서 위에 있는 것을 묻는다.
- 네가 다음 단계를 묻는 질문을 따로 할 때도 이 표의 질문은 빼지 않는다.
- 사용자가 '넘어가기'를 고르거나 답하지 않고 다른 말을 하면 다시 묻지 않는다.
- 사용자의 답은 work_note 의 decision 에 '물은 것 / 보여 준 선택지 / 사용자의 답(고름 또는 직접 씀)'으로 넣는다. 답을 받은 요청에서 자료실 도구를 쓰지 않았더라도 work_note 를 한 번 부른다.

## 지킬 것

- 대화에 없는 것은 짐작하지 않는다.
- 기록을 남겼다는 말은 답 끝에 한 줄이면 충분하다(예: "작업 기록을 남겼어요.").
